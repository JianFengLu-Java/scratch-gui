# 编程宇宙品牌字体

编辑器品牌区与站点导航、Footer 使用相同的字体和原生字重：中文得意黑 400，英文 Dancing Script 600。

- `SmileySans-Oblique.woff2`：与 `frontend-web/src/app/fonts/smiley-sans/` 的官方原始文件一致，授权见 `SmileySans-LICENSE.txt`。
- `DancingScript-Variable.ttf`：与 `frontend-web/src/app/fonts/dancing-script/` 的官方原始文件一致，授权见 `DancingScript-LICENSE.txt`。

字体随编辑器资源一起构建，独立打开 Web 或教师端编辑器时也可加载。
